Start with the material on your device

Paste a project brief, meeting notes or research summary. You can also select plain-text, Markdown, Word DOCX or text-based PDF files. In local mode, Slide extracts text in the browser rather than uploading the file for conversion. Scanned PDFs need OCR before importing. Review the extracted content and choose a shorter passage if the material exceeds the local model's context limit.

A useful brief tells the audience what happened, which facts support the message and what should happen next. Include real names, dates and numbers where relevant. Mark unknown results clearly. Slide helps organize the material, but you should check the final presentation against your source before sending it.

Choose how to create

On-device AI

Load a local model on a compatible WebGPU device, review its proposed outline, then generate the deck. The first use downloads model files; later loads can reuse the browser's cache. Performance and available memory vary by computer and browser.

Start without a model

Open a blank deck and edit it directly. Add, remove and reorder slides, change their text, and undo edits. This path does not require a model download or an AI-capable GPU.

A presentation you can take with you

Choose Download HTML to save the presentation as one file. Open that file in a browser to present it offline, use the navigation buttons or arrow keys, or select Print / Save PDF. The presentation file contains slide content and its layout; it does not need a model, account or live connection to Slide. Review the saved file before relying on it for an important presentation.

Use Save editable copy when you want to keep working on another device or preserve a backup. That project file includes source notes and editable slide data. Keep it private, and reopen it with Open editable project in Slide. Browser saves are convenient, but clearing browser storage can remove them, so download copies of important work.

Use Slide on a Mac or PC

Slide is a browser application. The blank-deck editor and offline presentation downloads do not depend on a native Mac app. On-device AI additionally requires compatible WebGPU support and enough memory for the selected model. The compact option is intended to reduce download and memory demands; the large model is for more capable hardware. Slide checks browser capabilities before loading, and never silently switches local work to a paid hosted model.

Optional hosted services

Hosted generation, account storage and web sharing are separate options in the editor. Selecting those features can send your chosen material to the service and its model provider. Review the current plan and privacy information in Slide before switching from local work. Downloading and presenting a local deck does not require buying the hosted plan.
